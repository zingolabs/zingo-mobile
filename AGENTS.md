# Agent instructions

These instructions bind every AI coding assistant working in this
repository. This file is the canonical source; `CLAUDE.md` is a symlink
to it.

## Written English style

Apply the guidance of Strunk and White's *The Elements of Style* to all
textual English output: conversational responses, commit messages, pull
request descriptions, documentation comments, code comments, CHANGELOG
entries, specifications, and architecture decision records.

Write full, grammatically correct sentences with proper punctuation.
Use the active voice and make definite assertions. Omit needless words,
but never at the cost of a sentence fragment. Do not write telegraphic
fragments, dash-chained clauses, or bullet lists of sentence fragments;
when a list genuinely clarifies, write each item as a complete
sentence.

## Project language

The glossary in [CONTEXT.md](./CONTEXT.md) defines this project's
terms. Use its language in code, commits, and discussion, and update it
when a term is resolved or retired.
